AP Lockheed Calipers, CP2696

The current prices listed at the end are current as of 05/04/17.

This set of pictures shows the top front view of the AP Lockheed Caliper, the bottom view and the back view. This caliper will work for both the Norvil Rotor (14_000002) and the stock Norton Rotor (06-1885). If this caliper is mounted to the Norton Fork Slider (06-3316) with the Norton Rotor (06-1885), you must use the Adapter Plate (14-200009). If this caliper is mounted to the Norton Fork Slider (06-3316) with the Norvil Rotor (14_000002), you must use the Adapter Plate (14-200010).

The caliper does not come with brake pads, but we stock two good pads that will fit this caliper.
AP Lockheed Brake Pads (14_200006)
EBP Brake Pads (14_000005)


Note: We have found it convenient to tap both caliper mounting lugs to accept a 3/8 x 24 Helicoil. The caliper mounting holes are just the correct size to accept the Helicoil tap. With this modification there is no need to have nuts on the back of the mounting lugs and installation and removal is fast and easy. This is especially convenient in a dual disc setup since one caliper must be removed to remove the wheel. In the following pictures this modification has been done.

This set of pictures show the Norvil disc mounted on the front wheel of a Commando. This is a two disc setup with matching Norvil sliders (13_200001) and AP Lockheed Calipers.
